## 部署指南

### 创建GitHub Pages步骤

1. **创建GitHub账号**
   - 访问 [GitHub官网](https://github.com/)
   - 注册账号，用户名设置为 `hjxok168`

2. **创建仓库**
   - 登录后，点击右上角「+」图标，选择「New repository」
   - 仓库名称必须设置为：`hjxok168.github.io`
   - 选择公开仓库（Public）

3. **配置GitHub Pages**
   - 进入仓库后，点击「Settings」
   - 找到「Pages」部分
   - 选择分支（通常为 main 或 master）
   - 点击「Save」保存设置

4. **上传网站文件**
   ```bash
   # 克隆仓库
   git clone https://github.com/hjxok168/hjxok168.github.io.git
   cd hjxok168.github.io

   # 添加网站文件
   git add .
   git commit -m "Initial commit"
   git push origin main
   ```

5. **等待部署完成**
   - GitHub Pages通常需要几分钟时间来部署网站
   - 完成后，可以通过 https://hjxok168.github.io 访问
